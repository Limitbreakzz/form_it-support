# ระบบจัดการข้อมูลงานบริการและบันทึกเวลาปฏิบัติงาน IT Support (เชื่อมต่อ Google Sheets)

เว็บแอปพลิเคชันระดับใช้งานจริง (Production-Ready) สำหรับจัดการข้อมูลการให้บริการ **IT Support** และบันทึกเวลาปฏิบัติงานของทีมงาน พัฒนาด้วย **React + TypeScript + Tailwind CSS** พร้อมระบบตัวอักษรภาษาไทย **IBM Plex Sans Thai** และเชื่อมต่อฐานข้อมูล **Google Sheets** ผ่าน **Google Apps Script API** อย่างปลอดภัย

## ขั้นตอนการติดตั้ง Google Sheets & Google Apps Script

1. สร้างไฟล์ Google Sheets ใหม่ที่ [https://sheets.new](https://sheets.new)
2. ในเมนูด้านบนของ Google Sheets คลิกที่ **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` ออกทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ [`google-apps-script/Code.gs`](./google-apps-script/Code.gs) ไปวางแทนที่ (สามารถกดปุ่มคัดลอกได้จากหน้า **"ตั้งค่า Google Sheets"** ภายในเว็บแอปพลิเคชันได้ทันที)
4. กดบันทึก (`Ctrl + S`)
5. คลิกปุ่ม **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**:
   - **เลือกประเภท (Select type)**: `เว็บแอป (Web app)`
   - **ดำเนินการในฐานะ (Execute as)**: `ฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: `ทุกคน (Anyone)`
6. คลิก **Deploy** อนุญาตสิทธิ์การเข้าถึง และคัดลอก **Web App URL** (`https://script.google.com/macros/s/.../exec`)
7. นำ **Web App URL** มาวางในเมนู **"ตั้งค่า Google Sheets"** บนหน้าเว็บแอปพลิเคชัน หรือกำหนดค่าในไฟล์ `.env`:
   ```env
   VITE_GAS_WEB_APP_URL=https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec
   ```

## การรันโปรเจกต์ในเครื่อง (Local Development)

```bash
# ติดตั้งแพ็กเกจ
npm install

# รันเซิร์ฟเวอร์สำหรับพัฒนา (http://localhost:5173)
npm run dev

# สร้างไฟล์สำหรับใช้งานจริง (Production Build)
npm run build
```
